# Social Media as a Mirror

### 📝 Project Description
This final year project analyzes user behavior and engagement patterns on social media platforms to reflect psychological trends and insights.

### 💻 Technologies Used
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Python (Django / Flask)
* **Database:** MySQL / SQLite
* **Documentation:** Included in the repository (`c16_major_project_documentation(1).docx`)

### 🚀 Key Features
* User Authentication & Profile Setup
* Social Media Data Analysis & Visualization
* Sentiment Analysis / Trend Reflection Dashboard

### 🛠️ How to Run the Project
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Open the project folder in your IDE (like VS Code).
3. Run the main project file to start the application.
